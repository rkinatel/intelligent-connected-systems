# Intelligent Connected Systems

> Research portfolio integrating Artificial Intelligence, Machine Learning, Internet of Things (IoT), Edge Computing, and Vehicular Networks.

## Overview

This repository serves as a centralized workspace for coursework, research activities, experiments, simulations, publications, and thesis development. It is designed to support the study and application of intelligent connected systems, with a particular focus on the convergence of AI, IoT, and next-generation communication networks.

## Research Areas

- Artificial Intelligence (AI)
- Machine Learning (ML)
- Deep Learning
- Internet of Things (IoT)
- Internet of Vehicles (IoV)
- Vehicular Networks
- V2X Communications
- Edge Computing
- Intelligent Transportation Systems (ITS)
- Smart Cities
- Wireless and Mobile Networks
- Data Analytics
